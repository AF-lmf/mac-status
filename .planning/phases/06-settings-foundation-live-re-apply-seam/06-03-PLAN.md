  <action>
    修改 MacStatus/MacStatus/UI/StatusBarManager.swift。

    不在 StatusBarManager 中注册 .settingsDidChange observer，不新增 settingsObserver 属性，
    不修改 init()。
    原因：MetricCollector（Plan 02）已注册 .settingsDidChange observer，外观变更时调用
    applyNow() → updateUI(sample:) → StatusBarManager.updateTitle(...)，重绘已由该路径驱动。
    StatusBarManager 是无状态的每帧渲染器；若它再注册一个只转发到 MetricCollector.applyNow()
    的 observer，会让每次外观变更触发两次 applyNow()（幂等但浪费）。故本 Plan 不添加任何 observer。

    重构 updateTitle 方法（替换现有 lines 73–103 的 switch mode 实现）：

    新的 updateTitle 逻辑：
    1. guard let button = statusItem.button else { return }
    2. 读取 let settings = SettingsManager.shared
    3. let order = settings.metricOrder（[Metric]）
    4. let enabled = Set(settings.enabledMetrics)（Set<Metric>，O(1) contains）
    5. let mode = settings.displayMode（DisplayMode）
    6. let active = order.filter { enabled.contains($0) }
    7. if active.isEmpty { button.title = "◆"; return }（最小占位字形）
    8. let result = NSMutableAttributedString()
    9. for (index, metric) in active.enumerated()：
       - if index > 0 { result.append(separator()) }（仅在非首 segment 前插入分隔符）
       - switch metric：
         - case .cpu:    result.append(cpuSegment(cpuUsage, mode: mode))
         - case .memory: result.append(memSegment(memoryStats, mode: mode))
         - case .network:result.append(netSegment(networkStats, mode: mode))
         - case .gpu:    result.append(gpuSegment(gpuStats, mode: mode))
         - case .battery:break（Phase 7 激活；此 case 不 append 任何内容）
    10. button.attributedTitle = result

    提取 per-metric segment helper 方法（private）：
    - cpuSegment(_ cpu: Double?, mode: DisplayMode) -> NSAttributedString
      mode=.full: "CPU: X%" / "CPU: --"；mode=.compact: "C:X%" / "C:--"；mode=.percentage: "X%" / "--"
      颜色：cpu 有值时 colorForUsage(cpu!, metric: .cpu)，否则 .secondaryLabelColor
    - memSegment(_ mem: MemoryStats?, mode: DisplayMode) -> NSAttributedString
      mode=.full: "MEM: X% L"（L=pressureLabel）；mode=.compact: "M:X%"；mode=.percentage: "X%"
      颜色：mem.usedPercent 有值时 colorForUsage(used, metric: .memory)，否则 .secondaryLabelColor
    - netSegment(_ net: NetworkStats?, mode: DisplayMode) -> NSAttributedString
      mode=.full: "NET: ↑X/s ↓X/s"；mode=.compact: "N:↑X↓X"；mode=.percentage: ByteFormatting.format(total)+"/s"
      颜色：.labelColor（网络无阈值着色）
    - gpuSegment(_ gpu: GPUStats?, mode: DisplayMode) -> NSAttributedString
      mode=.full: "GPU: X%" / "GPU: N/A"；mode=.compact: "G:X%" / "G:--"；mode=.percentage: "X%" / "--"
      颜色：gpu 有值时 colorForUsage(gpu!.utilizationPercent, metric: .gpu)，否则 .secondaryLabelColor

    保留现有 separator() 和 segment(_:color:) 辅助方法不变（它们是底层工具）。
    保留 pressureLabel(_:) 方法不变。

    删除以下方法（已被上述 per-metric helpers + 顺序循环取代）：
    - private func buildFullTitle(...)
    - private func buildCompactTitle(...)
    - private func buildPercentageTitle(...)

    删除内部 MetricType enum（private enum MetricType { case cpu, memory, gpu }）。

    升级 colorForUsage 方法签名（从 MetricType 改为 Metric）：
    private func colorForUsage(_ percent: Double, metric: Metric) -> NSColor

    新的 colorForUsage 实现：
    1. let settings = SettingsManager.shared
    2. warning = settings.customThresholds[metric.rawValue]?["warning"] ?? defaultWarning(for: metric)
    3. critical = settings.customThresholds[metric.rawValue]?["critical"] ?? defaultCritical(for: metric)
    4. if percent >= critical：
       - 尝试 settings.customColors[metric.rawValue]?["critical"]
         → NSColor(hex: hex) → 若非 nil 返回自定义色
       - 否则返回 .systemRed
    5. else if percent >= warning：
       - 尝试 settings.customColors[metric.rawValue]?["warning"] → NSColor(hex: hex)
       - 否则返回 .systemOrange
    6. 否则返回 .labelColor（semantic，随 dark/light 自适应）

    新增 defaultWarning(for:) 和 defaultCritical(for:) 私有方法：
    - defaultWarning：cpu → SM.cpuWarningThreshold；memory → SM.memoryWarningThreshold；gpu → 80.0；others → 80.0
    - defaultCritical：cpu → SM.cpuCriticalThreshold；memory → SM.memoryCriticalThreshold；gpu → 90.0；others → 90.0

    compact mode 中分隔符差异：
    现有 buildCompactTitle 用空格" "作分隔，buildFullTitle 和 buildPercentageTitle 用" | "。
    重构后统一行为：compact mode 下保持用空格分隔（与 v1.0 一致）；full/percentage 用 " | "。
    实现方式：separator() 方法根据 mode 返回不同分隔符，或在 updateTitle 中根据 mode 决定分隔符类型。
    推荐：updateTitle 中传入 sep 变量：
    - let sep = mode == .compact ? compactSeparator() : separator()
    新增 private func compactSeparator() -> NSAttributedString，返回单空格（与现有 buildCompactTitle 第 180 行一致的属性）。

    硬约束（per CONTEXT.md D-06）：
    - 绝对不在此方法中增删 NSStatusItem
    - 始终在 statusItem（单一合并 item）上条件组合 NSAttributedString
