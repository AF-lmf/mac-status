<interfaces>
From `TimerReader<T>`:
```swift
class TimerReader<T>: ReaderProtocol {
    let interval: TimeInterval
    var onUpdate: ((T?) -> Void)?
    func read()
    func start()
    func stop()
}
```

Required new interface:
```swift
enum GPUPressureLevel: Sendable, Equatable {
    case normal
    case warning
    case critical
}

struct GPUStats: Sendable, Equatable {
    let utilizationPercent: Double
    let pressureLevel: GPUPressureLevel?
}

final class GPUReader: TimerReader<GPUStats> {
    init()
    override func read()
}
```
</interfaces>
</context>

<threat_model>
| Threat | Severity | Mitigation |
|--------|----------|------------|
| IOKit service/key missing causes crash | high | Never force-unwrap IOService/CFProperty results; return `nil` through `onUpdate` |
| IOKit object leak during repeated polling | medium | Release iterators and services with `IOObjectRelease` on every read cycle |
| UI hangs from IOKit polling | medium | Keep all IOKit calls inside `GPUReader.read()` inherited background queue |
| Misleading stale GPU value | medium | Send `nil` on failure so Plan 03-02 can display `G --` |
</threat_model>

Implement:
- `import Foundation`
- `import IOKit`
- `enum GPUPressureLevel: Sendable, Equatable { case normal, warning, critical }`
- `struct GPUStats: Sendable, Equatable { let utilizationPercent: Double; let pressureLevel: GPUPressureLevel? }`
- `final class GPUReader: TimerReader<GPUStats>` with `init() { super.init(interval: 2.0) }`

Inside `read()`:
- Call `IOServiceGetMatchingServices(kIOMainPortDefault, IOServiceMatching("IOAccelerator"), &iterator)`.
- If the call fails or no iterator exists, call `onUpdate?(nil)` and return.
- Release the iterator with `defer { IOObjectRelease(iterator) }`.
- Iterate each service with `IOIteratorNext(iterator)` and release each service with `defer { IOObjectRelease(service) }`.
- Read `PerformanceStatistics` using `IORegistryEntryCreateCFProperty(service, "PerformanceStatistics" as CFString, kCFAllocatorDefault, 0)`.
- Extract a utilization value from these keys in order: `Device Utilization %`, `GPU Activity(%)`, `Renderer Utilization %`, `Tiler Utilization %`.
- Accept values that bridge as `NSNumber`; convert to `Double` and clamp to `0...100`.
- If multiple services return values, use the maximum valid utilization percent.
- Detect Apple Silicon with `sysctlbyname("hw.optional.arm64") == 1`.
- If Apple Silicon and utilization exists, map utilization to pressure: `< 60` normal, `60..<85` warning, `>= 85` critical.
- If no utilization was found, call `onUpdate?(nil)`.
- Otherwise call `onUpdate?(GPUStats(utilizationPercent: utilization, pressureLevel: pressureOrNil))`.

Keep formatting out of `GPUReader`. Formatting and color belong in `StatusBarManager` in Plan 03-02.
