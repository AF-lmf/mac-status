## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `FanReader` -> `MetricCollector` | Optional hardware telemetry enters the unified polling loop. |
| `MetricCollector` -> `DashboardState` | Current fan snapshot becomes popover UI state without persistence. |
| `UserDefaults` -> `SettingsManager` -> `DashboardView` | Local visibility preferences decide which row groups render. |
| `DashboardState` -> SwiftUI popover | Hardware capability and missing values become user-facing copy. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-02-T | Tampering | `showFanSection` UserDefaults | accept | Local visibility-only preference; it can hide/show rows but cannot write SMC keys or change fan behavior. |
| T-11-02-I | Information Integrity | `DashboardView` fan labels and copy | mitigate | Default numbered labels without position evidence; render nil as `N/A`; hide unsupported fan surfaces quietly. |
| T-11-02-D | Denial of Service | Optional fan values in SwiftUI | mitigate | Non-optional `FanSnapshot` default and optional formatting keep rows stable without crashes. |
| T-11-02-E | Elevation of Privilege | Fan control affordance in UI | mitigate | No buttons/sliders/mode controls/control-copy; grep blocks control terms and raw SMC keys. |
| T-11-02-R | Repudiation | Settings-driven repaint | accept | `applyNow()` reuses cached snapshots; no extra SMC reads or side effects are introduced. |
| T-11-SC | Tampering | package installs | mitigate | No npm/pip/cargo packages are installed in Phase 11; package legitimacy audit says none. |
</threat_model>
