<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AppleSMC -> `SMCReader` | Undocumented raw SMC bytes, type strings, and absent keys enter the app. |
| `SMCReader` -> `FanReader` | Optional decoded values must not become fake RPM, fake bounds, or control certainty. |
| `FanReader` -> downstream UI | Capability booleans and fan rows become user-facing information in later plans. |
| Xcode project -> app binary | New Swift source must compile in the app target without introducing extra dependencies. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01-T | Tampering | `SMCReader.decodeNumeric` | mitigate | Validate size/type before decoding; normalize only integer type whitespace and keep unknown formats returning nil. |
| T-11-01-I | Information Integrity | `FanReader` capability model | mitigate | Keep `rpmReadable`, `boundsReadable`, `targetReadable`, and `safeControlAvailable` separate; never infer safe control from readable RPM. |
| T-11-01-D | Denial of Service | AppleSMC absent or malformed fan keys | mitigate | Return unsupported/unreadable snapshots with optional nil fields; no thrown errors or modal surfaces. |
| T-11-01-E | Elevation of Privilege | AppleSMC write surface | mitigate | Do not add write constants, write helpers, helper/XPC, or control classes; enforce with grep gate. |
| T-11-SC | Tampering | package installs | mitigate | No npm/pip/cargo packages are installed in Phase 11; package legitimacy audit says none. |
</threat_model>
