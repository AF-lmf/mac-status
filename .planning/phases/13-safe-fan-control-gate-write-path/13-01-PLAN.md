<objective>
Run a fully isolated hardware write probe on Mac15,9 to verify — or falsify — the fail-closed gate (D-12/D-13) before any production write path is built.

Purpose: Research confirms SMC writes require root and the Ftst=1 unlock sequence (MEDIUM confidence for M3 Max specifically). This probe is the concrete hardware evidence gate. If the probe passes, Phase 13 plans 02–05 build the full production system. If the probe fails on any step, `safeControlAvailable` stays false and Phase 13 ships read-only per D-15.

The probe must run as root (via `sudo`). It is a standalone command-line Xcode target, never linked into the MacStatus app bundle.

Output: ProbeResult JSON printed to stdout; exit 0 = all steps passed; exit 1 = any step failed; fans confirmed in auto mode after exit regardless of outcome.
</objective>

    SMCWriteProbe.swift declares a ProbeResult struct (Codable, Sendable) with fields: success: Bool, steps: [ProbeStep], finalF0Md: Int?, finalF1Md: Int?, errorMessage: String?. ProbeStep is a Codable struct with: name: String, passed: Bool, detail: String.

    SMCWriteProbe.swift embeds an identical SMCParamStruct (80-byte, same 3 explicit pad bytes in SMCKeyInfoData — copy verbatim from SMCReader.swift lines 42–94). Add the 80-byte ABI guard (per PATTERNS.md shared pattern: assert MemoryLayout stride == 80) in the probe's open() function. The probe uses cmdWriteKey = 6 in addition to cmdReadBytes = 5 and cmdReadKeyInfo = 9. The call() function mirrors SMCReader.swift lines 177–191 exactly.

    SMCWriteProbe implements:
    - writeUI8(key: String, value: UInt8) throws — two-step: get key info (cmd=9), then write (cmd=6); must check BOTH kIOReturnSuccess AND output.result == 0 (per RESEARCH Pitfall 3). Throws ProbeError.writeFailed(key:smcResult:) if either check fails.
    - writeFloatRPM(key: String, rpm: Double) throws — encodes Float(rpm).bitPattern as 4 little-endian bytes (per RESEARCH Pitfall 5 / PATTERNS.md writeFloatRPM); writes via cmd=6 with the same double-check.
    - readUI8(key: String) -> UInt8? — uses cmd=5 read path.
    - readFloatRPM(key: String) -> Double? — decodes little-endian 32-bit float (inverse of writeFloatRPM; same as SMCReader.swift decodeNumeric flt path).

    SMCWriteProbe.run() executes the probe sequence and returns ProbeResult:

    STEP 1 — Record baseline: read F0Md and F1Md (expect 0 = auto). Record as "baseline_mode" step.

    STEP 2 — Write Ftst=1 (unlock thermalmonitord reclaim). Check output.result == 0. Record as "ftst_unlock" step.

    STEP 3 — Poll F0Md until mode != 3, max 10 seconds, 100ms intervals (per RESEARCH Pattern 3). If timeout expires, record "unlock_wait" step as failed, write Ftst=0 (cleanup), and return failure ProbeResult immediately.

    STEP 4 — Write F0Md=1, F1Md=1 (manual mode). Check output.result == 0 for each. Record as "mode_write" step.

    STEP 5 — Write F0Tg and F1Tg to a safe probe target RPM: choose a value halfway between the currently-read F0Mn and F0Mx. If bounds cannot be read, default to 2400.0 RPM (a safe mid-range value for Mac15,9 whose F0Mn ~ 1350, F0Mx ~ 6200). Use writeFloatRPM. Record as "target_write" step.

    STEP 6 — Release Ftst=0. Record as "ftst_release" step.

    STEP 7 — Wait 500ms for mode to settle (Task.sleep or Thread.sleep — this is the probe binary, blocking main thread is acceptable). Read back F0Md and F1Md. Mode must be exactly 1 (manual). Read back F0Tg — must be within ±1.0 of the written value (flt round-trip). Record as "readback_verify" step.

    STEP 8 — MANDATORY RESTORE (always runs, even if prior steps failed): write F0Md=0, F1Md=0, Ftst=0. Wait 300ms. Read back F0Md and F1Md — must be 0 (auto). Record as "restore_auto" step. If restore fails, record failure and still exit with a non-zero code so the fail-closed gate is triggered.

    main.swift: call SMCWriteProbe().run(), JSONEncoder-encode the ProbeResult with outputFormatting [.prettyPrinted, .sortedKeys], print to stdout. Exit 0 if result.success && all restore steps passed, else exit 1. The binary must be run as root (sudo) — add a guard at entry: if getuid() != 0 { print("ERROR: must run as root (sudo ./FanControlProbe)"); exit(2) }.

    Do NOT import AppKit, SwiftUI, or ServiceManagement in this probe target.
