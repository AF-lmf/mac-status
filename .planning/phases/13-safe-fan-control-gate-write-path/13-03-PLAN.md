| T-13-03-02 | Information Disclosure | False "手动已生效" UI state | mitigate | verifyManualMode required before state transitions to .manualVerified; IOKit success alone is never trusted; read-back checks F{i}Md == 1 exactly and F{i}Tg within ±1 RPM |
