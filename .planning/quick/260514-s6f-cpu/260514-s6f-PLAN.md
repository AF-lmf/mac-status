# Quick Task 260514-s6f: Menu Bar Memory Pressure Display

## Objective

Adjust the visible menu bar text to use the order `CPU | MEM | network`, and show memory pressure instead of used/total memory size.

## Tasks

### Task 1: Replace Memory Used/Total With Memory Pressure

**Files:**

- `MacStatus/MacStatus/Readers/MemoryReader.swift`
- `MacStatus/MacStatus/Utils/ByteFormatting.swift`
- `MacStatus/MacStatus/UI/StatusBarManager.swift`

**Action:**

- Read `kern.memorystatus_vm_pressure_level` with `sysctlbyname()`.
- Map pressure values to compact menu bar text:
  - `1` -> `MEM OK`
  - `2` -> `MEM WARN`
  - `4` -> `MEM CRIT`
  - unknown/error -> `MEM --`
- Render the combined status as `CPU ... | MEM ... | ↓... ↑...`.

**Verify:**

- `xcodebuild -project MacStatus/MacStatus.xcodeproj -scheme MacStatus -configuration Debug -derivedDataPath build build`
- Launch the Debug app and confirm the status item uses the new order.

## Success Criteria

- Menu bar text order is CPU, memory pressure, network.
- Memory display no longer shows used/total GB.
- Build succeeds.
