# Quick Task 260514-rj1: 把 CPU 并入可见网络菜单栏项显示

## Scope

The independent CPU status item still does not appear, while the network status item is visible. Use the visible network item as the primary menu bar display and prepend CPU usage there.

## Tasks

1. Stop relying on the independent CPU-only status item for visible CPU output.
2. Maintain cached CPU and network text in `StatusBarManager`.
3. Render a combined title on the visible network status item: `CPU --% ↓-- ↑--`, later `CPU 12% ↓1K ↑1K`.
4. Build and restart the app for verification.
