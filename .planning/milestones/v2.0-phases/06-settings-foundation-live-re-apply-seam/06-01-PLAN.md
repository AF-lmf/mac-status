    extension Notification.Name {
        static let settingsDidChange = Notification.Name("com.macstatus.settingsDidChange")
    }

    init()：private init() { runMigrations(); loadAll() }
    — runMigrations() 和 loadAll() 均直接操作 UserDefaults / _backing 变量，不经过 setter，

    runMigrations() 实现：
    - 读 defaults.integer(forKey: Keys.schemaVersion)，0 表示全新安装
    - if current < 1 { migrateToV1() }
    - 写入 defaults.set(1, forKey: Keys.schemaVersion)

    migrateToV1() 实现（全部直接写 UserDefaults.standard.set，绝不调用 self 的属性 setter）：
    - metricOrder：若 nil，写入 ["cpu", "gpu", "memory", "network"]（per D-04，compact 顺序）
    - enabledMetrics：若 nil，写入 ["cpu", "gpu", "memory", "network"]
    - refreshInterval：若 nil，写入 2.0
    - displayMode：若 nil，写入 "compact"
    - displayUnit：若 nil，写入 "auto"
    - showIcons：若 nil，写入 false（用 defaults.object(...) == nil 判断）
    - cpuWarningThreshold：若 nil，写入 60.0
    - cpuCriticalThreshold：若 nil，写入 80.0
    - memoryWarningThreshold：若 nil，写入 60.0
    - memoryCriticalThreshold：若 nil，写入 80.0
    - launchAtLogin：若 nil，写入 false
    - customThresholds / customColors：留 nil（代码默认值在 StatusBarManager 读取层面处理）

    loadAll() 实现（直接赋值给 _backing 变量，不调用 setter，不触发通知）：
    为以下每个属性从 UserDefaults 读取并赋值 backing var：
    refreshInterval、displayMode、displayUnit、showIcons、
    cpuWarningThreshold、cpuCriticalThreshold、memoryWarningThreshold、memoryCriticalThreshold、
    metricOrder（stringArray → compactMap(Metric.init(rawValue:))，空时回退到 [.cpu,.gpu,.memory,.network]）、
    enabledMetrics（同上）、launchAtLogin、
    customThresholds（data → JSONDecoder → [String:[String:Double]]，失败时 [:]）、
    customColors（data → JSONDecoder → [String:[String:String]]，失败时 [:]）

    每个属性的模式（以 refreshInterval 为例）：
    - @ObservationIgnored private var _refreshInterval: TimeInterval = 2.0
    - var refreshInterval: TimeInterval { get { _refreshInterval } set { _refreshInterval = newValue; defaults.set(newValue, forKey: Keys.refreshInterval); postChange(keys: [Keys.refreshInterval]) } }

    对 metricOrder 和 enabledMetrics：
    - 类型分别为 [Metric] 和 [Metric]（不是 Set，enabledMetrics 也用 [Metric] 存储以便 JSON 序列化和顺序保留，StatusBarManager 侧转为 Set<Metric> 做 contains 查询）
    - setter：写 [metric.rawValue] 数组到 defaults，然后 postChange

    对 customThresholds（[String:[String:Double]]）和 customColors（[String:[String:String]]）：
    - setter：JSONEncoder().encode(newValue) → Data → defaults.set(data, forKey:)；失败静默跳过；postChange

    对 launchAtLogin（Bool）：
    - setter：写 defaults、触发 SMAppService side-effect（do { if newValue { try SMAppService.mainApp.register() } else { try SMAppService.mainApp.unregister() } } catch { print(...) }）、postChange
    - 需要 import ServiceManagement

    postChange(keys:) 辅助方法：
    private func postChange(keys: Set<String>) {
        NotificationCenter.default.post(name: .settingsDidChange, object: self,
            userInfo: [SettingsManager.changedKeysUserInfoKey: keys])
    }

    input validation（per 安全要求）：
    - cpuWarningThreshold / cpuCriticalThreshold / memoryWarningThreshold / memoryCriticalThreshold 的 setter 中对 newValue 做 max(0, min(100, newValue)) clamp，防止 Phase 9 UI 输入非法值
    - customThresholds setter：编码前对每个 Double 值 clamp 到 0.0...100.0
    - customColors setter：编码前对每个 hex String 验证以 "#" 开头且长度为 7，过滤非法值（保留合法值，丢弃格式错误的条目）

    中作为新文件 MacStatus/MacStatus/Utils/NSColor+Hex.swift 创建。

    注意：不添加 @ObservationIgnored 标记到 static let shared — shared 本身是 nonisolated 存储属性，
    不参与 observation tracking。

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UserDefaults → SettingsManager.loadAll() | 外部存储读入内存；理论上可被恶意 plist 工具写入非法值 |
| customThresholds / customColors JSON Data | JSON 解码失败时需回退到空字典而非 crash |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering | SettingsManager threshold setters | mitigate | 对 cpuWarning/Critical/memWarning/Critical 做 max(0,min(100,newValue)) clamp；customThresholds setter 对每个 Double 值同样 clamp |
| T-06-02 | Tampering | customColors hex 字符串 | mitigate | setter 中过滤非法 hex（非 "#RRGGBB" 格式的条目不写入）；NSColor(hex:) 初始化器返回 Optional，nil 时回退到系统颜色 |
| T-06-03 | Denial of Service | JSONDecoder 解码 customThresholds/customColors | mitigate | 解码失败时 loadAll() 回退到 [:]，不 crash；若 JSON Data 损坏，下次 setter 写入时自动覆盖 |
| T-06-SC | Tampering | npm/pip/cargo 安装 | accept | 本阶段零外部包安装；无需 slopcheck |
</threat_model>
