    在 MacStatus/MacStatus/Readers/ 下创建 ProcessResourceReader.swift。文件结构如下：

    顶部：import Darwin 和 import Foundation（按 MemoryReader.swift/GPUReader.swift 的导入模式，`import Darwin` 覆盖全部 libproc 符号，无需 bridging header）。

    第一段：定义 `struct ProcessResourceUsage: Sendable, Equatable`，字段 processName: String、pid: Int32、cpuPercent: Double?（nil = 首帧，UI 显示"—"）、memoryBytes: UInt64（ri_phys_footprint 字节值）。参照 RESEARCH.md 精确字段定义。

    第二段：定义 `final class ProcessResourceReader`，内含：
    - 嵌套 struct `ProcessKey: Hashable`（字段：pid: Int32、startAbstime: UInt64，对应 ri_proc_start_abstime）
    - 嵌套 struct `SnapshotEntry`（字段：cpuTicks: UInt64 = ri_user_time + ri_system_time；wallTicks: UInt64 = mach_absolute_time() 采样时刻）
    - `private var prevSnapshot: [ProcessKey: SnapshotEntry] = [:]`（跨采样状态）
    - `func clearSnapshot()`：调用 prevSnapshot.removeAll()，由 popoverDidClose 调用（PROC-03 关闭清零）

    第三段：`func sample() -> ([ProcessResourceUsage], [ProcessResourceUsage])`（同步，从 Task.detached 调用）：
    1. 壁钟快照：let wallNow = mach_absolute_time()（与 ri_user_time 同单位，Mach ticks）。
    2. PID 枚举：proc_listpids 两次调用模式（per RESEARCH.md §"proc_listpids 缓冲区大小舞蹈"）——第一次传 nil+0 探测大小，第二次传实际缓冲；缓冲多分配 10%（count + count / 10）防竞争截断；从 actual 字节数计算 pidCount。
    3. 遍历 pids[0..<pidCount]：guard pid > 0（跳过 kernel_task pid 0）；调用 proc_pid_rusage(pid, RUSAGE_INFO_V4, UnsafeMutableRawPointer($0))，guard ret == 0（probe-and-skip，静默跳过 EPERM/ESRCH/已退出）。
    4. 从 rusage_info_v4 提取：cpuTicks = info.ri_user_time + info.ri_system_time；startAbstime = info.ri_proc_start_abstime；memBytes = info.ri_phys_footprint（不是 ri_resident_size）。
    5. CPU% delta：key = ProcessKey(pid:startAbstime:)；若 prevSnapshot[key] 存在，deltaCPU = cpuTicks >= prev.cpuTicks ? cpuTicks - prev.cpuTicks : 0（max(delta,0)）；deltaWall = wallNow > prev.wallTicks ? wallNow - prev.wallTicks : 0；deltaWall > 0 时 cpuPercent = min(Double(deltaCPU) / Double(deltaWall) * 100.0, 999.9)；否则 cpuPercent = nil（首帧）。
    6. 更新 newSnapshot[key] = SnapshotEntry(cpuTicks:wallTicks:wallNow)；循环结束后 prevSnapshot = newSnapshot。
    7. 进程名：var nameBuf = [CChar](repeating: 0, count: 256)；proc_name(pid, &nameBuf, UInt32(nameBuf.count))；nameLen > 0 时 String(cString: nameBuf)，否则 "PID \(pid)" fallback。
    8. CPU Top 5 排序：cpuPercent nil 进程用 -1 sentinel 排末尾；同值按 processName 升序 tie-break；prefix(5)。
    9. 内存 Top 5 排序：memBytes 降序；同值按 processName 升序 tie-break；prefix(5)。
    10. 返回 (cpuTop5, memTop5)。

    注意事项：
    - 不使用 mach_timebase_info（单位天然抵消，per RESEARCH.md 关键发现）。
    - 不使用 task_for_pid（per D-01 锁定决策）。
    - 不调用 sysctl(KERN_PROC_PID)（ri_proc_start_abstime 已在同一 proc_pid_rusage 调用中获得）。
    - withUnsafeMutableBytes 用于 proc_listpids 缓冲区传递（参照 PATTERNS.md 的两次调用示例）。
    - Swift 6 严格并发：ProcessResourceReader 是普通 final class，不是 actor；实例由单一 Task.detached 独占，编译器不报数据竞争（per RESEARCH.md §"Swift 6 并发分析"）。

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-08-01 | Spoofing | ProcessKey (pid, startAbstime) | mitigate | (pid, ri_proc_start_abstime) 复合键防 PID 复用冒名；max(delta,0) 防 delta 异常 |
