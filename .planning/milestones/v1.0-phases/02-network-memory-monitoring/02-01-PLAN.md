Then define `final class NetworkReader: TimerReader<NetworkStats>` with:

a) **Private state:**
   - `previousBytes: (download: Int64, upload: Int64)?` — stored baseline for delta calculation (nil on first read)
   - `previousTime: Date?` — timestamp of previous read

b) **`init()` calling `super.init(interval: 1.0)`** (D-06: network refresh 1 second)

c) **`override func setup()`** — initialize `previousBytes = nil`, `previousTime = nil`. Add an observer for `NSWorkspace.didWakeNotification` that resets `previousBytes` and `previousTime` to nil (PITFALLS P5: sleep/wake data freeze — counters are stale after sleep). Use a stored `NSObjectProtocol?` token for the observer so it can be invalidated in deinit. Read the RESEARCH.md code examples (lines 370-445) for the exact implementation pattern.

d) **`override func read()`** — the core data collection cycle, called on `.utility` background queue by TimerReader. Must do:
   1. Call `getPrimaryInterface()` to resolve current active interface name via `SCDynamicStoreCopyValue(nil, "State:/Network/Global/IPv4" as CFString)` → `dict["PrimaryInterface"] as? String` (D-03: never hardcode "en0")
   2. If interface is empty, call `onUpdate?(nil)` and return
   3. Call `readBytes(for: interface)` to get current (download, upload) as `(Int64, Int64)?`
   4. If `readBytes` returns nil, call `onUpdate?(nil)` and return
   5. Store `let now = Date()`, then check: if `previousBytes` or `previousTime` is nil, this is the first read — store the baseline in the `defer` block (step 7) and return without calling onUpdate
   6. Compute: `dt = now.timeIntervalSince(previousTime!)`, guard `dt > 0`. Then: `dlRate = Double(max(current.download - previous!.download, 0)) / dt`, `ulRate = Double(max(current.upload - previous!.upload, 0)) / dt` — D-07: `max(_, 0)` handles counter wraparound
   7. In a `defer` block (after the guard checks), update `previousBytes = current`, `previousTime = now`
   8. Call `onUpdate?(NetworkStats(downloadBytesPerSec: dlRate, uploadBytesPerSec: ulRate))`

e) **`private func getPrimaryInterface() -> String`** — use the RESEARCH.md Pattern 2 (line 221-229). Call `SCDynamicStoreCopyValue(nil, "State:/Network/Global/IPv4" as CFString)`, cast result to `[String: Any]`, extract `dict["PrimaryInterface"] as? String`, return it or `""` on failure.

f) **`private func readBytes(for interface: String) -> (download: Int64, upload: Int64)?`** — use the RESEARCH.md Pattern 1 (lines 197-209):
   - Call `getifaddrs(&ifap)`, guard return == 0 and `ifap != nil`
   - `defer { freeifaddrs(first) }` — PITFALL P3: always pair with freeifaddrs to prevent ~86 MB/day memory leak
   - Walk the linked list with `var ptr = first; while ptr != nil { ... ptr = ptr.pointee.ifa_next }`
   - At each node: get `ifa_name` via `String(cString: ptr.pointee.ifa_name)`, skip if `name != interface`
   - Check `ifa_addr?.pointee.sa_family == UInt8(AF_LINK)` (link-layer address → ensures `ifa_data` is `if_data`)
   - Cast `ptr.pointee.ifa_data` via `assumingMemoryBound(to: if_data.self)`
   - Return `(download: Int64(data.pointee.ifi_ibytes), upload: Int64(data.pointee.ifi_obytes))` — CRITICAL: convert `u_int32_t` → `Int64` before any subtraction to handle 32-bit counter wraparound (PITFALL P2)
   - Return `nil` if interface not found

g) **deinit** — remove the `NSWorkspace.didWakeNotification` observer if set.

**2. `MacStatus/MacStatus/Utils/ByteFormatting.swift`**

Create standalone formatting functions (do NOT hand-roll byte formatting — use Foundation `ByteCountFormatter` per RESEARCH "Don't Hand-Roll" section):

```swift
import Foundation

/// Format bytes-per-second for network rate display (1000-byte units, matching KB/s/MB/s convention).
func formatNetworkRate(_ bytesPerSec: Double) -> String {
    let formatter = ByteCountFormatter()
    formatter.countStyle = .file       // 1000-byte units
    formatter.allowsNonnumericFormatting = false
    return formatter.string(fromByteCount: Int64(bytesPerSec)) + "/s"
}

/// Format bytes for memory display (1024-byte units, matching GiB convention).
func formatMemoryBytes(_ bytes: Double) -> String {
    let formatter = ByteCountFormatter()
    formatter.countStyle = .memory     // 1024-byte units
    formatter.allowsNonnumericFormatting = false
    return formatter.string(fromByteCount: Int64(bytes))
}

/// D-01: Compact network rate format — "↓2.1M ↑512K" (strips trailing "/s" from arrow side).
func formatNetworkCompact(download: Double, upload: Double) -> String {
    let dl = formatNetworkRate(download).replacingOccurrences(of: "/s", with: "")
    let ul = formatNetworkRate(upload).replacingOccurrences(of: "/s", with: "")
    return "↓\(dl) ↑\(ul)"
}

/// D-02: Compact memory format — "MEM 8.2G/16G".
func formatMemoryCompact(used: Double, total: Double) -> String {
    let usedStr = formatMemoryBytes(used).replacingOccurrences(of: " ", with: "")
    let totalStr = formatMemoryBytes(total).replacingOccurrences(of: " ", with: "")
    return "MEM \(usedStr)/\(totalStr)"
}
```

Do NOT use `ByteCountFormatter.CountStyle.file` for memory — use `.memory` (1024-byte units).

**IMPORTANT:** These are free functions, not a class. No singleton, no state. They can be called from any context (Reader background queue or @MainActor StatusBarManager). Phase 1 pattern: SettingsManager uses a class with `@unchecked Sendable`, but for pure formatting functions with no state, free functions are the simplest Swift 6-compatible approach.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Kernel → NetworkReader | `getifaddrs()` returns kernel-allocated linked list of `ifaddrs` structs. Interface names and byte counters are kernel-provided — treat as untrusted data. |
| SystemConfiguration → NetworkReader | `SCDynamicStoreCopyValue()` returns CFDictionary from the dynamic store — cast safely with optional binding. |
| NSWorkspace notification → NetworkReader | `didWakeNotification` arrives on main thread — reader state mutation must be thread-safe. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | `getifaddrs()` linked list traversal | mitigate | Walk the list with bounded pointer arithmetic (`ifa_next`); check `ifa_addr.sa_family == AF_LINK` before reading `ifa_data`. `freeifaddrs()` in `defer` prevents memory leak. |
| T-02-02 | Information Disclosure | `SCDynamicStoreCopyValue` dictionary casting | mitigate | Guard with `as? [String: Any]` optional binding; extract `PrimaryInterface` via `as? String`. Return `""` on any cast failure — app shows "↓-- ↑--" rather than crashing. |
| T-02-03 | Information Disclosure | `if_data.ifi_ibytes`/`ifi_obytes` (u_int32_t) | mitigate | Convert to `Int64` before arithmetic. Use `max(delta, 0)` to handle wraparound into negative territory — prevents negative rate display leaking counter state. |
| T-02-04 | Denial of Service | `NSWorkspace.didWakeNotification` observer | mitigate | Observer block accesses reader state (`previousBytes`, `previousTime`) which is also accessed from Timer's background queue. Both are simple value assignments — no lock needed because writes are atomic for these types. |
| T-02-05 | Tampering | `StatusBarManager.attributedString()` text injection | accept | Menu bar text is generated from `ByteCountFormatter` output (numeric → formatted string) and fixed prefixes ("↓", "↑", "/s"). No user-controlled input reaches `attributedString`. Low-risk, no mitigation needed. |
</threat_model>
