  <action>
Modify `StatusBarManager.swift` and `ByteFormatting.swift` to implement the Phase 3 display contract.

In `StatusBarManager`:
- Change initial CPU text from `CPU --%` to `C --%`.
- Add `private var latestGPUText = "G --"`.
- Add `private var latestGPUPressure: GPUPressureLevel?`.
- Add `private var lastGPUStats: GPUStats?`.
- Change `updateCPU(_:)` to format successful values as `C %.0f%%`; nil remains `C --%`.
- Add `func updateGPU(_ stats: GPUStats?)`.
  - If `stats == nil`: set `latestGPUText = "G --"`, `latestGPUPressure = nil`, `lastGPUStats = nil`, then call `updateCombinedStatus()`.
  - If `stats` equals `lastGPUStats`, skip redraw.
  - Otherwise set `lastGPUStats = stats`, `latestGPUText = String(format: "G %.0f%%", stats.utilizationPercent)`, `latestGPUPressure = stats.pressureLevel`, then call `updateCombinedStatus()`.
- Change `updateCombinedStatus()` order to `latestCPUText`, `latestGPUText`, `latestMemoryText`, `latestNetworkText`.
- Keep GPU visible even when unavailable; never remove the GPU segment.
- Increase fixed `networkStatusItem` width enough for `C 100% | G 100% | M CRIT | ↓999M ↑999M`; use a conservative fixed width such as 300.
- Replace the combined title write path with a segment-aware attributed string:
  - Base font remains `NSFont.monospacedDigitSystemFont(ofSize: NSFont.smallSystemFontSize, weight: .regular)`.
  - Base foreground remains `NSColor.labelColor`.
  - Separator text uses base foreground.
  - Apply `NSColor.systemGreen`, `NSColor.systemYellow`, or `NSColor.systemRed` only to the GPU segment when `latestGPUPressure` is `.normal`, `.warning`, or `.critical`.
  - Do not color CPU or memory in Phase 3.

In `ByteFormatting.swift`:
- Change `formatMemoryPressure(.normal)` from `MEM OK` to `M OK`.
- Change `.warning` from `MEM WARN` to `M WARN`.
- Change `.critical` from `MEM CRIT` to `M CRIT`.
- Change `.unknown` from `MEM --` to `M --`.
  </action>
